## 三、断面②:Shader 渐变工厂 API(计划外)

### 旧 API(现代码所用)
`org.jetbrains.skia.Shader.make*Gradient(x/y/r0r1/startEndAngle, colors: IntArray, positions: FloatArray?, style: GradientStyle)`;`GradientStyle(tileMode, isPremul, localMatrix)`。

调用点(均为本仓库的 `paint/gradient/*` 3 个 `createShader`,外加 `RenderCustomClip` 的 debug 渐变):

1. `LinearGradient.createShader`(LinearGradient.kt:28-40)
2. `RadialGradient.createShader`(RadialGradient.kt:31-42 普通锥;45-59 two-point conical)
3. `SweepGradient.createShader`(SweepGradient.kt:28-40)
4. `RenderCustomClip.debugPaint`(RenderCustomClip.kt:37-45,`makeLinearGradient(x0..y1, colors=…, positions=…, style=GradientStyle(…).withTileMode(FilterTileMode.REPEAT))`)

### 新 API(javap 实测 skiko jar)
`GradientStyle` **已移除**。工厂改收一个值对象 `org.jetbrains.skia.Gradient` + 独立的 `localMatrix`,而不再收扁平的 `colors/positions/style`:

- `Shader.makeLinearGradient(x0, y0, x1, y1, gradient: Gradient, localMatrix: Matrix33?)`(另有 Point 重载;makeRadial/makeTwoPointConical/makeSweepGradient 同构,新增 startAngle/endAngle 于 sweep)
- `org.jetbrains.skia.Gradient(colors: Colors, interpolation: Interpolation)`
  - `Colors(color4f: Color4f[], positions: FloatArray?, tileMode: FilterTileMode, colorSpace: ColorSpace?)`
  - `Interpolation(inPremul: InPremul, colorSpace: ColorSpace, hueMethod: HueMethod)`(有默认构造)
- 颜色类型由 `IntArray` 变为 `Color4f[]`(需由 int ARGB 转换;`isPremul` 语义并入 `Interpolation.InPremul`;`localMatrix` 不再收进 style 而是工厂参数)。

### 迁移要点(方向性,未实现)
把 4 处旧的 `make*Gradient(...colors, positions, style=GradientStyle(tileMode, isPremul, localMatrix))` 改写为:

```
make*Gradient(<几何参数>, gradient = Gradient(
    Colors(color4fs, positions, tileMode, colorSpace=null),
    Interpolation(inPremul=…, colorSpace=…, hueMethod=…)
), localMatrix = …)
```
其中 `color4fs` 由仓库现有 `colors: IntArray` 逐色转换为 `Color4f`。仓库的 `Gradient.Transform`(`localMatrix`)仍按现有 `transform(rect).toRMO().asMatrix33()` 计算后作独立参数传入。

> 取舍提示:迁移集中在 4 个文件即可(仓库上层 `BoxDecorationPainter` 等只调用本仓库 `Gradient.createShader(rect)`,其契约不变)。若希望代码兼容旧/新快照,则需在此之上再抽象一层——本报告不推荐,除非确有双版本需求。

## 四、断面③:paragraph `FontRastrSettings` 弃用(计划外)

- 出错按 **错误** 处理(非警告;项目未开 `allWarningsAsErrors`,属 skiko 侧 `@Deprecated(level=ERROR)`),故不修则编译不过。
- 位置 `TextPainter.kt`:
  - `:288` 构造 `FontRastrSettings(edging=SUBPIXEL_ANTI_ALIAS, hinting=NORMAL, subpixel=true)`(即 `DEFAULT_FONT_RASTR_SETTINGS`)
  - `:81` 赋给 `ParagraphStyle().fontRastrSettings`
- 弃用提示指向新机制:这些设置已下沉到 **`TextStyle` 的 `fontEdging` / `fontHinting` / `subpixel` 三个独立属性**(`org.jetbrains.skia.paragraph.TextStyle`,新快照实测存在)。
- 迁移方向(未实现):停止在 `ParagraphStyle` 上设置 `fontRastrSettings` 与构造 `FontRastrSettings`,改为在文本样式(`TextStyle`)上设 `fontEdging = FontEdging.SUBPIXEL_ANTI_ALIAS`、`fontHinting = FontHinting.NORMAL`、`subpixel = true`(需先确认该默认值应落在 `DEFAULT_TEXT_STYLE` 或各文本 span;paragraph 级若确无替代字段,默认即该语义)。此点需在动手时用一次编译确认新 API 的准确归属。
